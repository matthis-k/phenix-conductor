## Decisions

- Reuse #503 generic `CallableRef` dispatch. Do not add a client-tool-specific callback protocol.
- Admissions are ephemeral and client-generation scoped.
- The application host owns admitted-client projection and execution. Providers see ordinary `ModelToolDescriptor` / `ModelToolCall` values and no client-origin metadata.
- Permission runs before generic callable dispatch. Input/output validation stays in the generic capability registry.
- ACP handlers that can trigger nested ACP traffic release the dispatch loop with `connection.spawn(...)` before awaiting that work.
- Observable delivery stays synchronous at the core SDK boundary.
