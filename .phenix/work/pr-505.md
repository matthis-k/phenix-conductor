## Decisions

- #503 is on main. Reuse its generic `CallableRef` and dispatcher rather than callback-specific transport.
- Admissions are ephemeral and generation scoped; the backend sees only ordinary `CallableDescriptor`s through `ToolProvision`.
- One ACP callback queue serves one client connection, so admission and invocation accept only that owner and generation.
- Provider adapters translate the backend-neutral model tool surface at the protocol boundary; providers do not gain a client-tool-specific path.
- `ToolProvision` stays origin neutral; admission ownership remains above the backend boundary.
- Session admission descriptor projection is deterministic by callable id before backend presentation.
- The application host owns the admitted-client execution adapter: permission runs before generic callable dispatch, while ACP transport remains a transport concern.
