## Decisions

- Observable resources stay ordinary runtime-owned `get` and `listen` callables. The listener is a generic client-owned `CallableRef`.
- The listener input uses the core canonical delivery schema. It preserves commit, value, version, address, subscription, generation, diff, and full-snapshot data.
- A successful observable stop removes its lifted local listener entry. Queued callbacks then fail before Lua dispatch, while a failed stop leaves the listener live.
- Keep runtime-to-client invocation on the same `CapabilityInvokeInput/Result` application callback. Do not add an observable-specific callback path.
- Admit client-owned callable leaves from the authoritative input schema before dispatch; the exact admitted schema remains the registry schema used for both input and output validation.
